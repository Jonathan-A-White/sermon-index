# Changelog

Newest first, one dated line per change a user of the service or its files could notice; a breaking change says so first.

- 2026-11-05: The theme tier. `GET /v1/sermons?ref=rom.5.8&tier=theme` answers `{ref, passage, theme}`: the passage rows as before, then the sermons whose preaching text shares a topic with the ref (a topic of at most 300 verses, `store.ThemeMaxVerses`), each once with its narrowest topic named in `theme: {source, topic, label, part, part_label}` and never repeating a passage row; `tier=theme-only` leaves out the passage rows (`"passage": null`), `theme=<source:topic>` restricts to a topic, and `limit` and `offset` apply to each tier. Without `tier` the answer is unchanged. `GET /v1/themes?ref=` rows gain `sermons` (sermons on the topic by preaching text) and `verses` (the topic's width). Migration `0003_theme_verses` adds `themes.verses`: **run `sermons migrate` and then `sermons load --all sources/`**, or the theme tier finds no topic. Over the real files Romans 5:8's theme tier is 364 sermons (Thompson's two topics alone 74, Torrey's five alone 323). docs/api.md, "The theme tier".
- 2026-11-05: The theme sources `themes-tcr1934` (Thompson Chain Topics, the 1934 subject index: 1,728 topics, 2,229 parts, 27,076 links) and `themes-torrey` (Torrey's New Topical Textbook: 628 topics, 38,849 links), written by `tools/sword-themes` from CrossWire's SWORD modules TCR and Torrey, each with the module's licence quoted verbatim; Thompson's `licence_note` records a search of the 1961-62 renewal catalogues for registration A72501 (no entry found). `GET /v1/themes?ref=rom.5.8` now answers 2 Thompson topics and 5 Torrey ones, and `rom.5` 23 and 33. Psalm numbering in both is the KJV's, as Lampas's; docs/sources.md, "Theme sources", lists the 62 psalms where Hebrew numbering would shift a verse.
- 2026-11-05: The source `spurgeon-ccel`: C. H. Spurgeon's sermons from CCEL, 3,543 rows (3,539 entries; one row a sermon number) of which 3,467 have a preaching text, written by `tools/ccel-spurgeon` (which fetches CCEL's 63 ThML volumes into a git-ignored cache and keeps only numbers, titles, references and addresses), with CCEL's terms quoted verbatim. `sermons check --urls` now fetches a `ccel.org` page and reports a 200 whose page does not hold the row's title (CCEL answers 200 to any address).
- 2026-11-05: `sermons serve`, the read-only HTTP API `/v1` (docs/api.md): `/v1/health`, `/v1/sources`, `/v1/sermons?ref=&source=&limit=&offset=` (preaching text first, narrower first), `/v1/themes?ref=`, `/v1/search?q=`; CORS for Lampas's origins, ETag and five-minute caching, gzip, 60 requests a minute per client IP, a log line a request. Migration `0002_search` adds full-text search columns; run `sermons migrate`. `make build` stamps the version.
- 2026-11-05: The first version: the `sermons` binary with `migrate`, `check` and `load`; schema v1 (sources, sermons and their passages as verse-ordinal ranges with a GiST index, themes, theme parts and theme links); the source-directory format (`source.toml` with the licence verbatim, `rows.jsonl`, `topics.jsonl`, `links.jsonl`); a template and a twenty-sermon Spurgeon fixture.
